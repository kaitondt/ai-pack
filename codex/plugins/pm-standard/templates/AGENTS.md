## The rules that override default behaviour

1. **Compare against the baseline.** Status without a baseline is activity, not progress.
2. **A baselined artifact changes only through approved change control** (PB-03). A hook
   enforces this.
3. **Never move a baseline to make a variance disappear** (PB-06). The variance is the
   information. Re-baselining is a governance decision with a retained history.
4. **Nothing enters scope without a change request** (PB-07) — not the small useful addition,
   especially not that one. Ten absorbed four-hour changes is a week nobody can account for.
5. **Every estimate carries method, basis, range and assumptions** (ES-01), and is never
   derived backwards from a target (ES-02).
6. **Padding is forbidden; buffers are mandatory** (ES-05). Uncertainty is held visibly at
   project level, not hidden inside individual estimates.
7. **Every number in a report has a source and an as-of date** (RI-02). Not collected is a
   legitimate status; invented is not.
8. **Progress follows `{{profile.schedule.progress_measurement}}`**, never self-assessment
   (RI-03). There is no 90%.
9. **RAG is computed from thresholds, then explained** (RI-04). Never green over a red section.
10. **Bad news moves immediately** (RI-05), through the escalation path, not on the cadence.
11. **One named owner per decision, risk, issue, action and work package** (DA-01, DA-06). A
    team is not an owner.
12. **A decision is recorded when it is made, or it did not happen** (DA-03). The log is
    append-only; a reversal is a new entry.
13. **No automatic version bump** (MD-02). Add a revision row only when told to, or when an
    approval baselines the document.
14. **A metric is never improved by reclassifying the work behind it** (RI-09, QP-07).
15. **Report honestly.** A slipping milestone is reported slipping, with the recovery option
    and its cost.

## The planning order, which is not negotiable

```
charter → scope statement → WBS → WBS dictionary → activities → estimate
       → resource plan → schedule → cost baseline → quality plan → risk register → PMP
```

A schedule produced before the WBS is a list of dates. A cost baseline produced before the
resource plan is a spreadsheet. A risk register written last is a list of things that already
happened.
