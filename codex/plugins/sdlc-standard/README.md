# sdlc-standard for Codex

Install this plugin, copy `templates/profile/sdlc.profile.yaml` to `.codex/sdlc.profile.yaml` in the target repository, copy `templates/rules/` to `.codex/rules/`, then copy `templates/AGENTS.md` to `AGENTS.md`. Use `$sdlc_workflow` or describe the lifecycle task naturally. The former Claude slash-command procedures remain in `references/commands/` as compatibility documentation.
